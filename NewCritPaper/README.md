# A new criterion for integral modular categorification

Jingcheng Dong and Sébastien Palcoux

Theorem 1.1 bounds the nonzero entries of a column of the modular $S$-matrix and gives a divisibility condition for a non-invertible simple object in the adjoint subcategory. The [Python implementation and reproduction instructions](python/README.md) explain how these two conditions are used to test candidate types.

- [Input lists and their sources](python/README.md#data-sources)
- [All 358 rank-15 types passing the tests](python/data/rank15-survivors.txt)
- [Reproduce the counts](python/reproduce.py) and [verify them independently](python/verify.py) with the Python 3.9+ standard library.
